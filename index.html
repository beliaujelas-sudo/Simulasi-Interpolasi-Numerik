A. Konsep Dasar Interpolasi

1. Definisi Interpolasi

Dalam analisis numerik, interpolasi adalah proses atau metode matematika untuk mengestimasi nilai fungsi kontinu $p(x)$ yang dapat memprediksi nilai fungsi asal $f(x)$ pada titik-titik yang belum diketahui. Proses ini didasarkan pada sekumpulan data diskret tunggal $(x_0, y_0), (x_1, y_1), \dots, (x_n, y_n)$ di mana setiap absis $x_i$ bernilai unik dan memenuhi kondisi pencocokan titik sampel ($p(x_i) = y_i = f(x_i)$).

2. Formulasi Titik Data

Secara matematis, himpunan data awal direpresentasikan sebagai sekumpulan pasangan titik $(x_0, y_0), (x_1, y_1), \dots, (x_n, y_n)$ di mana $x_0 < x_1 < \dots < x_n$, dan $y_i = f(x_i)$.

3. Perbedaan Interpolasi dan Ekstrapolasi

  • Interpolasi: Estimasi nilai $x = a$ dilakukan di dalam interval domain data sampel $[x_0, x_n]$.
  • Ekstrapolasi: Estimasi nilai $x = a$ dilakukan di luar interval tertutup ($a < x_0$ atau $a > x_n$).

B. Bentuk Umum Interpolasi Polinom

Untuk $n+1$ titik data diskret yang berbeda, dipastikan terdapat tepat satu (unique) fungsi polinom $p_n(x)$ berderajat paling tinggi $n$ yang melewati semua titik tersebut:

$$p_n(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n = \sum_{i=0}^{n} a_i x^i$$

C. Jenis-Jenis Interpolasi Polinom & Contoh Soal

1. Interpolasi Linier (Derajat 1)

Menghubungkan 2 titik data $(x_0, y_0)$ dan $(x_1, y_1)$ membentuk sebuah garis lurus murni.

$$p_1(x) = y_0 + \frac{y_1 - y_0}{x_1 - x_0}(x - x_0)$$
Contoh Soal:
$x_0 = 1, y_0 = 22$ dan $x_1 = 3, y_1 = 28$. Taksir suhu pada $x = 2$!
Penyelesaian: $$p_1(2) = 22 + \frac{28 - 22}{3 - 1}(2 - 1) = \mathbf{25^\circ\text{C}}$$

2. Interpolasi Kuadratik (Derajat 2)

Menggunakan 3 titik data $(x_0, y_0), (x_1, y_1), (x_2, y_2)$ membentuk kurva parabola.

$$p_2(x) = a_0 + a_1 x + a_2 x^2$$
Contoh Soal:
$(0,0), (2,8), (4,24)$. Taksir nilai pada $t = 3$!
Penyelesaian: $p_2(t) = 2t + t^2 \implies p_2(3) = 2(3) + (3)^2 = \mathbf{15}$

3. Interpolasi Kubik (Derajat 3)

Menggunakan 4 titik data untuk membentuk kurva lengkung berderajat tiga.

$$p_3(x) = a_0 + a_1 x + a_2 x^2 + a_3 x^3$$
Contoh Soal:
$(0,1), (1,2), (2,9), (3,28)$. Taksir nilai pada $x = 1{,}5$!
Penyelesaian: $p_3(x) = 1 + x^3 \implies p_3(1{,}5) = 1 + (1{,}5)^3 = \mathbf{4{,}375}$
